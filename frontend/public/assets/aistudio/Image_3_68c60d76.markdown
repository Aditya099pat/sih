# DESIGN SYSTEM: AICTE Security Deposit & FDR Management Portal (PS26265)
## 1. Product Overview & Purpose
A mission-critical statutory portal for the All India Council for Technical Education (AICTE), Ministry of Education, Government of India. The portal digitizes, verifies, monitors, and audits the multi-year lifecycle of institutional Security Deposits, Fixed Deposit Receipts (FDRs), and Refundable Performance Guaranty Funds (RPGF).
## 2. Visual Tone & Aesthetic
- Tone: Authoritative, trustworthy, modern GovTech, high-density enterprise SaaS.
- Visual Language: Crisp borders, subtle shadows, professional contrast, clutter-free tabular layouts, and clear visual hierarchy.
- Target Canvas: Desktop 1440px wide layout, responsive down to 1024px.
## 3. Color Palette & Tokens
- Primary Brand: AICTE Deep Navy (`#0D3B66`, `#1E3A8A`) - Used for primary headers, active sidebar states, and main CTAs.
- Secondary / Accent: Sovereign Gold / National Saffron Accent (`#E65100`, `#F59E0B`, `#D97706`) - Used for active tabs, focus rings, notifications, and highlights.
- Backgrounds: 
  - Canvas Base: `#F8FAFC` (Slate 50)
  - Surface / Cards: `#FFFFFF` (White)
  - Secondary Panels / Viewer BG: `#0F172A` (Slate 900) or `#F1F5F9` (Slate 100)
- Typography:
  - Heading & Display: `Inter`, system sans-serif (Font weights: 600, 700)
  - Body & Data Tables: `Inter`, tabular numbers (`font-mono` / `font-feature-settings: 'tnum'` for FDR numbers, amounts, IFSC, and UTRs)
- Semantic Status Colors:
  - Compliant / Verified / Active (>180 Days): Emerald Green (`#059669`, bg: `#ECFDF5`)
  - Warning / Maturing Soon (15–90 Days): Amber Yellow (`#D97706`, bg: `#FFFBEB`)
  - Overdue / Discrepancy / Sanction Freeze / Defaulter: Crimson Red (`#DC2626`, bg: `#FEF2F2`)
  - In Scrutiny / Pending Review: Sky Blue (`#0284C7`, bg: `#F0F9FF`)
## 4. UI Component Specifications
- Buttons: Rounded-lg (8px), font-medium, padding: px-4 py-2. Primary (Navy), Success (Emerald), Danger (Red), Ghost (Slate border).
- Cards: Background white, border `border-slate-200`, rounded-xl (12px), subtle shadow `shadow-sm`.
- Tables: Sticky header, alternating row highlights on hover (`hover:bg-slate-50`), bold primary keys (PID, FDR No.), right-aligned currency amounts formatted with `₹` symbol in Indian numbering format (e.g., ₹35,00,000 or ₹1,05,00,000).
- Badges: Pill-shaped, text-xs, font-semibold, px-2.5 py-0.5, border matching text color tint.
